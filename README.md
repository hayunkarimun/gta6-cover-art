Entry untuk bounty [Make GTA 6 Cover Art](https://make.fun/bounty/gta6-cover-art-01) di [make.fun](https://make.fun) — web app offline yang mengubah foto + caption jadi cover art gaya poster GTA, lalu export PNG siap dibagikan. Foto tidak pernah meninggalkan mesin kamu.

## Fitur

- Dua mode layout: **Film Strip** (satu foto hero besar + strip kolase 3 foto dengan sprocket holes) dan **Poster** (full bleed satu foto)
- 4 preset color grade: Golden Hour, Midnight Neon, Pastel Vice, Mono Pop — plus slider kontras/saturasi manual
- Judul besar gradasi sunset/neon, subjudul, dan badge sudut "EST. 2026"
- Tiap foto bisa di-drag (pan) dan di-zoom (scroll/slider); muat foto via file picker atau drag-and-drop
- Export PNG dalam ukuran post umum: 1080×1350, 1080×1080, 1920×1080, 1200×630
- 100% offline: font sistem saja, tanpa network saat runtime

## Cara jalanin

```bash
node serve.ts
```

Lalu buka `app/index.html` di browser (atau http://localhost:8080). Pilih foto, atur strip/panel, ganti grade, edit judul/subjudul/badge, lalu klik Export untuk mengunduh PNG.
